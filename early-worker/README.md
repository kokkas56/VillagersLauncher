# Ранний доступ — как включить (один раз, ~20 минут)

Новые сборки можно выпускать сначала для тех, кто поддерживает (Boosty), и для друзей, а в назначенный день — для всех.
Рассчитано на тысячи игроков: файлы ранних версий лежат в хранилище Cloudflare R2 (10 ГБ и скачивание — бесплатно),
люди и коды — в базе Cloudflare D1. Всё это бесплатно; если игроков станет очень много — тариф Workers Paid ($5/мес).

## Права (уровни)
| Кто | Что получает |
|---|---|
| Друг | все ранние версии, бессрочно |
| «Навсегда ко всему» | все ранние версии, бессрочно (крупный донат / особый уровень) |
| Подписка до даты | все ранние версии, **вышедшие до этой даты** — после окончания они остаются у человека навсегда, новые — уже вместе со всеми |
| Отдельная версия | конкретная ранняя версия навсегда (разовый донат) |

## 1. Cloudflare (один раз)
1. Зарегистрируйся на https://dash.cloudflare.com (бесплатно).
2. **R2 Object Storage** → включи R2 (может попросить карту для верификации; бесплатный объём — 10 ГБ) → **Create bucket** → имя `villagers-early`.
3. **Storage & Databases → D1** → **Create database** → имя `villagers-early`.
4. **Workers & Pages** → **Create** → **Create Worker** → имя `villagers-early` → **Deploy**.
5. Открой воркер → **Edit code** → удали всё → вставь содержимое `worker.js` → **Deploy**.
6. Воркер → **Settings → Bindings** → **Add**:
   - **R2 bucket**: имя переменной `FILES`, бакет `villagers-early`;
   - **D1 database**: имя переменной `DB`, база `villagers-early`.
7. Воркер → **Settings → Variables and Secrets** → **Add** (тип Secret):
   - `SECRET` — любая длинная случайная строка (40+ случайных букв и цифр);
   - `ADMIN_KEY` — ещё одна длинная случайная строка. Это **ключ автора**: его знает только твой лаунчер, никому не давай.
   - **Deploy**.
8. Скопируй адрес воркера: `https://villagers-early.<твоё-имя>.workers.dev`.

Таблицы в базе воркер создаст сам при первом запросе.

## 2. Лаунчер
«Автор» → **Ранний доступ**:
- **Адрес воркера** и **ссылка на Boosty** → «Сохранить настройки» (это видят все лаунчеры и сайт);
- **Ключ автора** — `ADMIN_KEY` из шага 1.7 → «Сохранить».

Появятся: статистика, добавление людей, поиск, коды, ранние выпуски.

## 3. Как давать доступ
**Вручную** (друзья, особые случаи): «Добавить человека» → ник Ely.by → друг / навсегда / подписка до даты.
В списке у каждого: «+31 дн.» — продлить, ★ — сделать другом, корзина — удалить.

**Кодами с Boosty** (тысячи людей, без ручной работы):
1. «Коды для Boosty» → вид: *подписка на N дней* (для подписочного уровня), *текущая ранняя версия навсегда* (разовый донат) или *навсегда ко всему* → лимит активаций → «действует до» → **Создать код**.
2. Вставь код в **закрытый пост** нужного уровня на Boosty (например, «Код на ноябрь: ABCD-EFGH-JKLM»).
3. Игрок: лаунчер → «Настройки → Сборка → Ранний доступ» → вводит код → «Активировать». Права привязываются к его Ely.by.
4. Раз в месяц — новый код для подписки (старый можно удалить или дать ему истечь). Один человек активирует каждый код только один раз; подписочные коды продлевают срок от текущей даты окончания.

## 4. Как выпускать
- «Залить сборку» → галочка **«Ранний доступ»** → дата «Открыть всем» (по умолчанию через 2 недели).
- В назначенный день лаунчер автора сам переносит выпуск в общий GitHub при запуске. Можно раньше — «Открыть всем».
- Обычная заливка без галочки — сразу для всех, как раньше.
- На сайте над новостями появится плашка «★ Ранний доступ: сборка #N уже у поддержавших, для всех — такого-то числа».

## Важно знать
- Это защищает от случайного скачивания, но не от того, что кто-то с доступом перешлёт файлы.
- Сторонние моды (Create и т. п.) лаунчер берёт с Modrinth — за доступ к ним брать деньги нельзя; закрываются только твои файлы.
- Правила Mojang о платных модах — серая зона: ранний доступ за поддержку распространён, но официального разрешения нет.
- Если у кого-то не открывается `*.workers.dev`, привяжи к воркеру свой домен (Worker → Settings → Domains & Routes).
