# Ранний доступ — как включить (один раз, ~15 минут)

Новые сборки можно выпускать сначала только для тех, кто поддерживает (Boosty), а потом — для всех.
Друзьям доступ даётся бесплатно и бессрочно.

Как это устроено:
- ранние выпуски лежат в **закрытом** репозитории GitHub;
- их выдаёт маленький бесплатный сервер **Cloudflare Worker** (файл `worker.js`) — только тем, чей ник Ely.by есть в списке доступа;
- список доступа — файл `access.json` в том же закрытом репозитории; правится в лаунчере: «Автор» → «Ранний доступ».

## 1. Закрытый репозиторий
1. GitHub → **New repository** → имя `MineVillagers-early`, **Private**, галочка «Add a README file» → Create.
2. Токен, который уже стоит в лаунчере (раздел «Автор»): GitHub → Settings → Developer settings → Fine-grained tokens → твой токен → **Edit** → Repository access: добавь `MineVillagers-early` → Contents: **Read and write** → Update.

## 2. Токен только для чтения (для воркера)
GitHub → Fine-grained tokens → **Generate new token**:
- Repository access: **только** `MineVillagers-early`;
- Permissions → Contents: **Read-only**;
- срок — побольше (например, год). Скопируй токен.

## 3. Воркер Cloudflare
1. Зарегистрируйся на https://dash.cloudflare.com (бесплатно).
2. **Workers & Pages** → **Create** → **Create Worker** → имя `villagers-early` → **Deploy**.
3. **Edit code** → удали всё → вставь содержимое `worker.js` → **Deploy**.
4. Worker → **Settings** → **Variables and Secrets**:
   - Text: `EARLY_REPO` = `kokkas56/MineVillagers-early`
   - Secret: `GH_TOKEN` = токен из шага 2
   - Secret: `SECRET` = любая длинная случайная строка (например, 40 случайных букв и цифр)
   - **Deploy**.
5. Скопируй адрес воркера: `https://villagers-early.<твоё-имя>.workers.dev`.

## 4. Лаунчер
«Автор» → **Ранний доступ**:
- Адрес воркера — из шага 3.5;
- Закрытый репозиторий — `kokkas56/MineVillagers-early`;
- Ссылка на Boosty — твоя страница;
- **Сохранить настройки**.

Потом добавь людей: ник Ely.by, «друг (бессрочно)» или дата «до какого дня», заметка (например, ник на Boosty) → **Сохранить список**.

## Как выпускать
- «Залить сборку» → галочка **«Ранний доступ»** → дата «Открыть всем» (по умолчанию через 2 недели).
- В назначенный день лаунчер автора сам переносит выпуск в общий (при запуске). Можно раньше — кнопка **«Открыть всем»**.
- Обычная заливка без галочки — сразу для всех, как раньше.

## Важно знать
- Это защищает от случайного скачивания, но не от того, что кто-то с доступом перешлёт файлы другу.
- Сторонние моды (Create и т. п.) лаунчер и так берёт с Modrinth — их нельзя «продавать», закрываются только твои файлы.
- Правила Mojang о платных модах — серая зона: ранний доступ за поддержку распространён, но официального разрешения нет.
- Если у кого-то не открывается адрес `*.workers.dev` — можно привязать свой домен к воркеру (Cloudflare → Worker → Settings → Domains).
