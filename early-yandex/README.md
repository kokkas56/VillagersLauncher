# Ранний доступ на Яндекс Облаке — как включить (один раз, ~20 минут)

Почему Яндекс: принимает российские карты, а скачивание из России идёт на полной скорости
(Cloudflare российские провайдеры с 2025 года режут — файлы бы не скачались).

Как устроено: файлы ранних версий лежат в твоём **бакете Object Storage**. Маленькая **функция** (`index.js`)
проверяет игрока через Ely.by и выдаёт ссылки на файлы только тем, у кого есть права. Люди и коды хранятся
в том же бакете. Платишь только за то, что используется; на старте почти всё укладывается в бесплатный объём
(точные цены — на сайте Яндекс Облака, раздел «Тарифы»).

## Права (уровни)
| Кто | Что получает |
|---|---|
| Друг | все ранние версии, бессрочно |
| «Навсегда ко всему» | все ранние версии, бессрочно |
| Подписка до даты | все ранние версии, **вышедшие до этой даты** — после окончания остаются навсегда |
| Отдельная версия | конкретная ранняя версия навсегда (разовый донат) |

## 1. Аккаунт
1. Открой https://console.yandex.cloud и войди Яндекс ID.
2. Создай **платёжный аккаунт** (российская карта подходит; новым пользователям обычно дают стартовый грант).
3. Создастся облако и каталог `default` — дальше всё в нём.

## 2. Бакет (хранилище)
1. **Object Storage** → **Создать бакет**.
2. Имя — уникальное, латиницей, например `villagers-early-kokk`.
3. Доступ на чтение объектов, к списку объектов и к настройкам — **Ограниченный** (закрытый). Остальное — по умолчанию → **Создать**.

## 3. Сервисный аккаунт и ключ
1. **Identity and Access Management** → **Сервисные аккаунты** → **Создать** → имя `early-fn` → роль **`storage.editor`** → **Создать**.
2. Открой `early-fn` → **Создать новый ключ** → **Статический ключ доступа** → **Создать**.
3. Скопируй **идентификатор ключа** и **секретный ключ** (секрет показывают один раз!).

## 4. Функция
1. **Cloud Functions** → **Создать функцию** → имя `villagers-early` → **Создать**.
2. На вкладке «Обзор» включи **Публичная функция**.
3. **Редактор** → среда выполнения **Node.js 18** (или новее) → способ **Редактор кода** → **Создать файл** `index.js` → вставь содержимое `index.js` отсюда.
4. Точка входа: `index.handler`. Таймаут: **30 секунд**. Память: **128 МБ**.
5. **Переменные окружения**:
   - `BUCKET` — имя бакета из шага 2;
   - `S3_KEY_ID` — идентификатор ключа из шага 3;
   - `S3_SECRET` — секретный ключ из шага 3;
   - `SECRET` — любая длинная случайная строка (40+ букв и цифр);
   - `ADMIN_KEY` — ещё одна длинная случайная строка. Это **ключ автора**, никому не давай.
6. **Сохранить изменения** (создастся версия).
7. Скопируй **ссылку для вызова** функции: `https://functions.yandexcloud.net/d4e…`.

## 5. Лаунчер
«Автор» → **Ранний доступ**:
- **Адрес функции** (шаг 4.7) и **ссылка на Boosty** → «Сохранить настройки» (это видят все лаунчеры и сайт);
- **Ключ автора** — `ADMIN_KEY` → «Сохранить».

Появятся: статистика, «Добавить человека», поиск, коды для Boosty, ранние выпуски.

## Как давать доступ
**Вручную** (друзья, особые случаи): «Добавить человека» → ник Ely.by → друг / навсегда / подписка до даты.
У каждого в списке: «+31 дн.» — продлить, ★ — сделать другом, корзина — удалить. Поиск — по началу ника.

**Кодами с Boosty** (тысячи людей, без ручной работы):
1. «Коды для Boosty» → *подписка на N дней* / *текущая ранняя версия навсегда* / *навсегда ко всему* → лимит активаций → «действует до» → **Создать код**.
2. Вставь код в **закрытый пост** нужного уровня на Boosty.
3. Игрок: «Настройки → Сборка → Ранний доступ» → вводит код → «Активировать». Права привязываются к его Ely.by.
4. Раз в месяц — новый код подписки. Каждый человек активирует код один раз; подписка продлевается от текущей даты окончания.

## Как выпускать
- «Залить сборку» → галочка **«Ранний доступ»** → дата «Открыть всем».
- В этот день лаунчер автора сам перенесёт выпуск в общий GitHub при запуске (или раньше — «Открыть всем»).
- Обычная заливка без галочки — сразу для всех, как раньше.
- На сайте над новостями появится плашка «★ Ранний доступ: сборка #N уже у поддержавших».

## Важно
- Защищает от случайного скачивания, но не от того, что кто-то с доступом перешлёт файлы.
- Сторонние моды лаунчер берёт с Modrinth — закрываются только твои файлы.
- Правила Mojang о платных модах — серая зона: ранний доступ за поддержку распространён, но официального разрешения нет.
